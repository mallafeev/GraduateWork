# Phylo App Prototype v5

Что изменено:
- убран метод Bayesian из UI и из доступных вариантов построения
- оставлены только `Neighbor Joining` и `Maximum Likelihood`
- построение дерева методом ML перенесено в фоновый поток, поэтому окно не зависает во время расчёта
- ускорен старт приложения:
  - загрузка ML/RF-предиктора и связанных тяжёлых модулей теперь отложена до первого реального использования
  - поиск предзагруженных моделей больше не делает рекурсивный обход больших каталогов при старте

## Зависимости

```bash
python -m pip install pyqt5 biopython matplotlib pandas joblib scikit-learn numpy
```

## Запуск

```bash
python main.py
```

## Как использовать

1. Загрузить alignment (`.nex/.nexus/.fasta`)
2. Построить `NJ` или `ML` дерево
3. При необходимости загрузить `model_v1.pkl`
4. Нажать **Предсказать bootstrap**
5. Смотреть результаты в таблице и на дереве
